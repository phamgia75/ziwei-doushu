# Known limitations

1. **Calendar convention.** (Historical rule implemented: the Vietnamese calendar equals the Chinese one before 1968, and in the South until 1975-04-30; the North/South split uses 17°N and the 1975-04-30 boundary is an approximation.) Default charts use the Chinese (UTC+8) lunar calendar like upstream. Vietnamese and Chinese
   lunar dates differ on 1,137 days in 1950–2026 (chart changes on ~1,079). The app warns on those dates; the
   opt-in "Lịch âm Việt Nam" remaps them, except 34 days whose Vietnamese lunar date does not exist in the Chinese calendar.
2. **Mean solar time by default.** Upstream applies longitude only; the equation of time (±16 min, ~6 % of birth minutes
   change double-hour) is an opt-in setting.
3. **Historical time zones** come from the runtime's ICU tzdata (Asia/Ho_Chi_Minh) and a 17°N north/south rule;
   1945–1954 zones in contested areas are approximations. Places outside Vietnam need manual longitude + offset.
4. **Only three school conventions are selectable** (late Tý, leap month, brightness table) plus calendar/EoT. Other
   upstream school options exist only as UI config without engine support and are not exposed.
5. **AI quality** depends on the local model, which still makes factual slips (caught and flagged inline). The claim verifier is
   pattern-based: it decides placements, brightness, Mệnh/Thân Chủ, tam hợp, xung/hội chiếu, giáp, Tứ Hóa (by scope) and per-person
   compatibility claims; other relationship sentences are shown as "chưa kiểm chứng", and free-form doctrine is not checked.
   Answers still run longer than the 450-word instruction. Interpretations are cultural, not scientific.
6. **Dataset**: covers 1950–2026 only, generated by an earlier engine build; records whose Mệnh main star disagrees with
   our chart are not shown. Readings are machine-translated on demand (≈2–3 s per paragraph once the model is loaded);
   translations failing checks are labelled.
7. **Classical texts** stay in the original with on-demand machine translation; translations are not proof-read.
8. **PDF export** uses the browser print dialog (prints the chart and the visible tab).
9. **Engine verification** is a consistency check (golden snapshot of this engine + iztro, which the engine builds on)
   plus an independent lunar algorithm; no third-party reference charts were compared.
10. Chat history lives in the page only (not saved). Client-held history is sanitised but could contain forged assistant turns.
11. `@types/node` is v20; the zstd API is typed via a local cast (runtime Node ≥ 22.15 required for the dataset).
12. **Fresh AI answers take ~18–32 s** on qwen3.5:35b (generation-bound); exact repeats are instant from the local answer cache.
13. **Translation QA** is automated (Han leftovers, length, terminology) — 42/45 pass; not human proof-read.
14. **PDF report** omits Chinese glyphs (no CJK font bundled) and shows natal Tứ Hóa only in the grid.
15. **Licences**: Next.js's optional `sharp` pulls LGPL-3.0 libvips binaries into `node_modules` (not committed or redistributed).
16. Commercial production release is not approved; this remains a local, non-public application.
